# W09 run 002 — council record

## Options considered

| Option | Merits | Failure mode | Council position |
|---|---|---|---|
| Base44 for all programme functions | Fastest single interface | Competing truth, non-exportable users and sensitive-data residency risk | Reject |
| New custom stack immediately | Maximum theoretical control | Delays delivery and duplicates an existing Moodle estate before fit testing | Defer |
| Separable stack with Moodle fit test and Base44 as projection | Reuses existing capability while preserving migration | Requires disciplined adapters, exports and ownership | Recommend |

## Chairman synthesis

Approve the requirements and fit-test method, not a vendor award. Base44 remains useful precisely because it is treated as replaceable. Moodle receives a presumption of testing, not a presumption of fitness.

## Conditions

1. Q009 must be answered before production personal data or retained transcripts are configured.
2. W10 must provide the operating calendar and support windows.
3. W12 must approve the data inventory and retention matrix.
4. A restore test, accessibility audit and migration rehearsal are launch evidence, not post-launch improvements.
