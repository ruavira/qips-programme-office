# W01 run 001 — benchmark and options

## Benchmark

| Comparator | What it reveals | QIPS adaptation | Why this is an improvement, not a shortcut |
|---|---|---|---|
| IHI Improvement Advisor | Premium applied offer requires a workplace improvement project and structured support | Test project access and sponsor/equivalent support in interviews | Connects programme fit to work the person can actually undertake |
| ISQua Fellowship | Broad international, online and income-banded route | Test accessibility and cross-country relevance without assuming one persona | Preserves reach while exposing local constraints |
| NAHQ framework | Competency language across a broad quality workforce | Use domains as prompts, not imported conclusions | Lets local task evidence confirm, reject or add competencies |
| WHO multi-professional guide | Safety capability is relevant across professions | Recruit clinical, non-clinical and informal quality-role participants | Prevents the sample from containing only titled quality officers |
| Punjab Healthcare Commission e-certification | Free/regulatory standards learning is a real substitute | Ask what applied coaching, cross-setting learning and portfolio evidence add | Forces QIPS to prove value beyond content access |

## Options

### A — title-led segment

Recruit only people already called quality officers. Easy to find, but systematically misses ward,
IPC, audit, patient-experience and operational staff doing quality work without the title.

### B — task-and-context segmentation

Recommended. Segment by work performed, decision authority, setting, project access, support and
career transition. Titles remain descriptors, not the definition.

### C — cadre-led marketing segments

Useful for channel planning but risks fragmenting one cross-functional capability system into
profession silos.
