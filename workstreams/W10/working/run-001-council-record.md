# W10 run 001 — council record

## Options considered

| Option | Advantage | Failure mode | Council position |
|---|---|---|---|
| One fixed programme-office clock | Simple to administer | Makes global participation an individual burden | Reject |
| Duplicate every live event | Maximum time choice | Doubles faculty load and creates inconsistent experiences | Reserve for evidence-based need |
| One tested window with rotation/equivalence trigger | Controlled load and explicit fairness | Requires cohort data and disciplined equivalence design | Recommend |

## Chairman synthesis

Approve the event contract, monthly runbook and fairness rules first. Exact dates must follow verified dependencies and calendars. Attendance must never be mistaken for competence.

## Conditions

- Preserve F013 and the approved month-based design.
- Do not publish F023 as confirmed.
- Obtain participant-zone/access data before fixing the live window.
- W03/W07 must govern consequences; W11 must evaluate access and equivalence.
