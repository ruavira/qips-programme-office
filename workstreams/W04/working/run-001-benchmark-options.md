# W04 run 001 — benchmark and options

## Benchmark

| Comparator | What it does | QIPS difference | Why better, not cheaper |
|---|---|---|---|
| Imperial observership | Documented eligibility, health/background checks, induction, confidentiality, authority and supervisor agreement; no hands-on work | Apply a multi-professional, quality-system observation scope under local law | Preserves tested safety boundaries while aligning activity to programme outcomes |
| Derby/Burton attachment | No patient-care responsibility; named supervisor; informed patient consent | Prefer non-patient operational/QI observation and require explicit consent if a patient context is unavoidable | Minimises privacy/clinical risk without pretending the setting is non-clinical |
| AHPRA guidance | Supervisor capability, preparation, cultural safety, feedback, resources and structured learning | Use a preceptor standard plus site capacity evidence | Makes supervision an assessable resource rather than a goodwill promise |
| AUC hospital visits | Eight five-hour visits embed operational exposure | Permit an approved split schedule totalling 40 hours | Improves feasibility while keeping the full governed evidence requirement |

## Options

### A — one five-day block

Simple and immersive; fragile for staff schedules, site capacity and missed days.

### B — approved block or split schedule totalling 40 hours

Recommended. Every session must map to outcomes and the same evidence controls.

### C — project-site observation only

Operationally easiest but may reproduce the participant's current system and create conflicts; use
only if it meets the same standard and the learning comparison remains credible.
