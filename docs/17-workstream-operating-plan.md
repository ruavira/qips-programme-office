# QIPS seventeen-workstream operating plan

This is the programme-office execution order. It does not change canon or cohort scope. It
organises work so the CCC receives no more than three decision-ready dossiers per cycle.

## Standard cycle for every workstream

1. Read canon, reconciliation issues, prior decisions and the workstream workspace.
2. Research through the workstream's declared lenses and record every live source with an accessed date.
3. Benchmark named comparators and state why any difference is an improvement rather than a shortcut.
4. Develop two or three defensible options.
5. Run the independent council and chairman synthesis.
6. Run adversarial verification; unresolved BLOCKING findings stop submission.
7. Submit the fixed-format dossier, link the Drive review copy and await a CCC verdict.

Human collaborators can comment and edit working documents. Only the CCC can promote facts,
close questions, change cohort scope or approve public commitments.
