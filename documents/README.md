# Document collaboration layer

Use Google Drive for Word, Docs, Sheets and Slides that need human commenting or direct editing. Use `register.yaml` to prevent ambiguous masters.

Every registered document must identify its owning workstream, content status, repository source, Drive link, version and next action. APPROVED means approved for the stated audience; it does not automatically mean public.

Binary working files should not be copied into multiple folders. Keep one review copy in Drive and one text-first source or generation record in GitHub whenever practical.
