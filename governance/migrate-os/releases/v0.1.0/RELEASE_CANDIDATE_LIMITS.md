# Release Candidate Limits

The package has passed its validator and unit tests but has not yet completed:

- a full source export from the ITC Base44 app;
- a complete Supabase schema and RLS rehearsal;
- migration of all demonstration records and files;
- parity tests for all 73 live server actions;
- a Next.js vertical slice against the target backend;
- final-delta and rollback rehearsals.

Until those are complete, the package must be described as release candidate rather than production-proven.
