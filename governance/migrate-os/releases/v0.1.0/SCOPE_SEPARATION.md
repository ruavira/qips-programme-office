# Scope Separation

MIGRATE-OS is domain-neutral and does not contain QIPS curriculum, HEFAMAA standards, ITC production data or other project content in its reusable core.

The ITC migration profile is an implementation example and does not make the ITC application part of QIPS canon. Registration in this repository provides governed history because IKR-POS is maintained here; it does not merge the substantive scopes of the projects.
